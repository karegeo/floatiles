FloaTiles — LCCA simulation

On-lattice cluster–cluster aggregation, ported to JavaScript from the C reference implementation (lcca_v18). Clusters diffuse with size-dependent mobility, stick on face contact with probability pstick, and lose surface cells at rate ε; evaporated cells re-deposit as monomers nearby, conserving the total tile count. ← back to project page

Density φ = N / (W·H). Each colour is a distinct cluster; colour is hashed from the cluster ID, so newly created clusters get fresh colours. Changing density triggers a reset.

Algorithm faithful to FloaTiles LCCA v18: 50×50 hard-walled grid, isotropic 8-direction movement (cardinal weight 1, diagonal 1/√2), size-dependent mobility 1/Aγ, per-face sticking, union-find + BFS relabel after merge, surface evaporation with teleport at 1 < Chebyshev distance ≤ 2.
